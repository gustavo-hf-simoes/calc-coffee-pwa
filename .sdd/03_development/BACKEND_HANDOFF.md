# Backend & Runtime Handoff — CoffeeApp (Calc Coffee)

## Servidor Local & Ferramentas
- **Linguagem**: JavaScript Vanilla / Node.js (apenas para desenvolvimento e testes).
- **Servidor Dev**: `node serve.js` (servidor HTTP leve nativo zero-dependency).
- **Túnel Mobile**: `cloudflared.exe` configurado para expor porta local para teste no celular real.
- **Auditoria de Sintaxe**: `node --check js/*.js`.
