# Frontend Handoff — CoffeeApp (Calc Coffee)

## PWA Mobile-First
- **HTML Shell**: `index.html` com viewport mobile otimizada (`viewport-fit=cover`).
- **Estilos**: `css/style.css` com variáveis de cores nórdicas:
  - Fundo: `#f7f3ee`
  - Cards: `#ffffff`
  - Tipografia: `#3b2a1f`
  - Acento: Terracota `#c08457`
- **Componentes**:
  - Touch targets mínimos de 48px para ergonomia em aparelhos touchscreen.
  - Barra de navegação inferior com 4 ícones SVG.
  - Cronômetro central com anel circular de progresso.
